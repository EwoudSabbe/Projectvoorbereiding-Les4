Git - Version Control System

A simple introduction to Git

What is Git?

Git is a distributed version control system created by Linus Torvalds in 2005. It helps developers track changes in source code during software development.

Why Use Git?

  • Track changes in code
  • Collaborate with other developers
  • Manage different versions of a project
  • Revert to previous versions when needed

Basic Git Commands

Here are some commonly used Git commands:

  • git init – Initialize a new repository
  • git add . – Stage all changes
  • git commit -m "message" – Save changes
  • git status – Check current status
  • git push – Upload changes to remote repository
